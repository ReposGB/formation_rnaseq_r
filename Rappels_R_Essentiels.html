Environnement et utilisation

Nous utilisons l’environnement RStudio, qui est une interface développée indépendamment de R. RStudio existe sous les principaux systèmes d’exploitation et consiste en un IDE complet comprenant:

  • Invite de commande R
  • Un éditeur de texte avec coloration syntaxique
  • Un éditeur de différents formats de documents basées sous R (Rapports et présentations (RMarkDown)
  • Un terminal bash
  • Une aide R intégrée
  • Un gestionnaire d’historique
  • Un gestionnaire d’objets R
  • Un explorateur de fichiers

Accès RStudio IFB par l’adresse: https://ondemand.cluster.france-bioinformatique.fr/

Utilisation de R “basique”

Fonctions

Les fonctions prennent en entrée des objets de manière optionnelle. On peut également spécifier des options. Les options ont des valeurs par défaut. Les fonctions renvoient un objet en résultat. Les fonctions sont elle-même des objets. Un opérateur fait référence aux opérateurs mathématiques, tels que + qui ne sont pas invoqués avec des parenthèses.

Exemple: la fonction ls permet de lister les objets en mémoire:

ls()
## character(0)

Données

Tableaux de données : DataFrames

Un DataFrame est une structure de données tabulaire composée de lignes et de colonnes.

  • Chaque ligne représente une observation (échantillon, patient, gène…).

  • Chaque colonne représente une variable (âge, expression, condition…).

  • Les colonnes peuvent contenir différents types de données : numérique, texte, facteur, logique…

Créer un dataframe

patients <- data.frame(
  Patient = c("P1", "P2", "P3", "P4"),
  Age = c(45, 62, 51, 38),
  Sex = c("F", "M", "F", "M"),
  Treatment = c("Control", "Drug", "Drug", "Control"),
  Expression = c(12.5, 18.3, 15.2, 10.8)
)

# Afficher le dataframe

Creation à partir d’un fichier

Un DataFrame peut être créé directement à partir d’un fichier par un appel à read.csv ou read.csv2.

# Fichier CSV séparé par des virgules

data <- read.csv("patients.csv",
                 header = TRUE,
                 sep = ",")

# Fichier CSV séparé par des points-virgules

data <- read.csv2("patients.csv")

Accédér aux colonnes d’un dataframe

# Accéder à une colonne par son nom
patients$Age

# Autre méthode
patients[["Age"]]

# Accéder à une colonne par son index
patients[, 2]

Accédér aux lignes et colonnes d’un dataframe

# Première ligne
patients[1, ]

# Deuxième colonne
patients[, 2]

# Première ligne, deuxième colonne
patients[1, 2]

# Lignes 1 à 3 et colonnes 1 à 3
patients[1:3, 1:3]

# Sélectionner plusieurs colonnes par leur nom
patients[, c("Patient", "Age")]

Filtrer le contenu d’un dataframe

# Patients âgés de plus de 50 ans
patients[patients$Age > 50, ]

# Patients ayant reçu le traitement Drug
patients[patients$Treatment == "Drug", ]
# Combiner plusieurs conditions
patients[patients$Age > 40 & patients$Sex == "F", ]
##   Patient Age Sex Treatment Expression
## 1      P1  45   F   Control       12.5
## 3      P3  51   F      Drug       15.2
